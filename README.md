# Pocket Heist

Starter project for the Claude Code Masterclass on NetNinja.dev

A Next.js 16 mission management application where users can create, assign, and complete workplace "heists" (fun office tasks/challenges).

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.

## Tech Stack

- Next.js 16.0.7 with App Router
- React 19.2.0
- TypeScript 5
- Tailwind CSS 4
- Lucide React (icons)
- Vitest + React Testing Library (testing)
- ESLint 9

## Development Commands

```bash
npm run dev      # Start dev server
npm run build    # Create production build
npm start        # Run production server
npm run lint     # Run ESLint
npm run test     # Run tests
npm run test -- --ui  # Run tests with UI
```
